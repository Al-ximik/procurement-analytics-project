# Power BI File

Place the final Power BI Desktop file in this folder, for example:

```text
Procurement_Analytics.pbix
```

The repository already includes dashboard screenshots in `../images/` and the DAX measures in `../docs/powerbi_dax_measures.md`.

If you do not want to publish the `.pbix` file, the project can still be presented through the screenshots, SQL scripts, data dictionary, and documented insights.
