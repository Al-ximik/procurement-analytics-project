# Data

This folder contains the synthetic source data used in the project.

| File | Purpose |
|---|---|
| `procurement_transactions_raw.csv` | 10,000 procurement transactions |
| `suppliers.csv` | Supplier dimension (120 suppliers) |
| `departments.csv` | Department dimension (12 departments) |
| `categories.csv` | Category dimension |

The data intentionally contains missing values and formatting variations so that data-quality profiling and cleaning can be demonstrated.
